# 右滑采用「出价换物」语义（B 语义），并由推荐算法锁定出价物品

「想换」不是泛泛的「我喜欢你的东西」（A 语义），而是「我用我的某件物品换你的这件物品」。右滑瞬间，系统用推荐算法（`src/services/recommend.ts`）从我的闲置物品中锁定一件「出价物品」参与匹配；匹配成立时优先用出价物品，若对方右滑的是我另一件物品，则以对方实际选择为准。

**为什么不是 A 语义**：A 语义下「愿望单」只是装饰信息，匹配本质还是 Tinder 的互点喜欢，弹窗里展示「你的物品」会误导用户。B 语义让愿望单成为匹配的真实依据，符合「异步交换、无需同时在线」的产品定位。

**为什么用推荐算法而非人工选择**：右滑要求零摩擦，不能让用户每次右滑前先挑「用哪件换」。算法按愿望命中（40%）、品类偏好（20%）、价值对等（15%）、物品健康度（15%）、距离（10%）加权排序锁定 top-1，并把完整排序作为兜底。
