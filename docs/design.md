# 换换 Truke · 视觉设计（v2 旧货市集 → v3 森林绿）

> 依据 `frontend-design` 技能产出。原简报的暖米色 `#F5F0E8` + 橙色 `#E8572A` 恰好命中 AI 生成设计的第一号「穿帮」模板（暖米底 + 陶土点缀），因此保留「温暖、有手感、轻玩味」的精神，但把视觉锚点从「奶油橙」换成「旧货市集」题材本身：牛皮纸、价签、印章、邮戳、条形码。

## 题材锚点

二手闲置交换 = 跳蚤市场 / 旧货市集 / 快递面单 / 价签与印章。设计的一切质感都从这里来，而不是通用 SaaS 卡套。

## 排版

微信小程序只能用系统字体，因此在**字重、字距、数字排版**上做文章，而不是换字体：

- 标题：PingFang SC `900`，大字距收紧（`letter-spacing: -2rpx`），中文标题不再加全角空格装饰。
- 正文/标签：`500/700`，句首大写式（sentence case），不用全大写眉题。
- **数字**（距离 `0.8km`、价格 `¥6`、币数 `30`）：加粗 + 等宽数字（`font-variant-numeric: tabular-nums`，不支持时退化为统一字重），右对齐更「票据感」。
- 去掉「`A · B · C`」中点连接和「`WORD — 片段`」式标签——这些是模板化信号。

## 布局

卡片不再是「照片 + 信息」的 SaaS 卡套，而是一枚**旧货价签/挂牌**：

```
┌─────────────────────────────┐
│ 〔9成新 印章〕        〔⚡已Boost〕│   ← 印章式成色标签（旋转+双边）
│                             │
│         物品图 / emoji        │
│                             │
│ ┄ 想换：机械键盘 / 胶片相机 ┄  │   ← 虚线价签条（打孔感）
├─────────────────────────────┤
│  罗技 G613 机械键盘           │   ← 左对齐，900 重
│  🐻 熊仔      📍0.8km  9成新 │
│  ▍▍ ▍▍▍ ▍ ▍▍ ▍▍ ▍▍ ▍      │   ← 条形码（编码物品 ID，可玩性）
└─────────────────────────────┘
```

- 对齐：卡片内容**左对齐**；数字右对齐；匹配弹窗居中。
- 圆角：从 40rpx 降到 **24rpx**，摆脱「所有东西同圆角」的卡套感。
- 阴影：从大软阴影改为 **1–2rpx 实色描边 + 小阴影**，像印刷品而非悬浮卡片。
- 打孔虚线边：卡片边缘一条 dashed 描边，呼应邮票/票券的撕边。

## 原则

1. **大胆只花在一处**：滑动卡片是主角（价签质感）；其余页面安静克制。
2. **动效克制**：只有一次编排式入场 + 匹配彩带；不做散落的 hover/fade。
3. **文案是设计**：主动语态、动作一致（「发布」→「已发布」）、空状态是行动邀请而非情绪安慰。
4. **绿色=正向、红色=否定、棕色=中性、金色=付费**——一套语义稳定的信号系统。

## 自我批判（第二遍）

- ❌ 原「奶油底 + 橙色」→ ✅ 换成「牛皮纸 + 邮局绿/印章红」：题材从「通用温暖」收窄到「旧货市集」。
- ❌ 原「所有卡片 40rpx 圆角 + 同款软阴影 + 渐变洗色」→ ✅ 24rpx 圆角 + 实色描边 + 虚线撕边，去掉照片区渐变洗色。
- ❌ 原「`A · B · C` 元信息串、全大写眉题」→ ✅ 左对齐 + 等宽数字 + 句首大写。
- ❌ 原「散落的 hover/淡入」→ ✅ 单一编排动效。
